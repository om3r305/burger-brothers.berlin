# Burger Brothers Android

- Paket: `berlin.burgerbrothers.app`
- Başlangıç: `/?source=android-twa`
- Teknoloji: Trusted Web Activity / Bubblewrap
- Backend: mevcut Burger Brothers Next.js, Supabase ve Stripe sistemi

Bu klasör kaynak şablondur. Gerçek Android proje ve imzalı APK,
`tools/mobile/Build-BB-Android-Suite.ps1` ile repo dışındaki çalışma klasöründe üretilir.
Keystore bu klasöre veya GitHub'a konmaz.
