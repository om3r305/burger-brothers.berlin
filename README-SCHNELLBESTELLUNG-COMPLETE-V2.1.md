# Schnellbestellung Complete V2.1

Bu hedefli paket Complete V2 typecheck sırasında görülen iki hatayı düzeltir:

- Checkout PauseState artık `dineIn: false` içerir.
- Schnellbestellung kampanya metadata'sı Prisma JSON input tipleriyle uyumludur.
- Regression testine iki koruma eklendi.

ZIP içeriğini `C:\Web\burger` üzerine çıkarın ve
`RUN-SCHNELLBESTELLUNG-COMPLETE-V2.1-GITHUB-PUSH.bat` dosyasını çalıştırın.

Gönderim scripti, GitHub'a henüz gitmemiş Complete V2 kodlarının tamamını
V2.1 düzeltmeleriyle birlikte test/build/commit/push eder.
