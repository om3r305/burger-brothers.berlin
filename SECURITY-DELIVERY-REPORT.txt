BURGER BROTHERS SECURITY HARDENING — FINAL REPORT
Tarih: 17.07.2026

TAMAMLANANLAR
1. Admin/TV cookie güvenliği
- Admin ve TV cookie'leri süreli HMAC-SHA256 imzalıdır.
- HttpOnly, SameSite=Lax, production Secure ayarları korunur.
- İmzasız ok:/1 cookie taklidi reddedilir.
- Base64URL non-canonical imza varyasyonları da reddedilir.

2. API yetkilendirme
- /api/admin ve /api/tv imzalı rol oturumu gerektirir.
- Sipariş listeleme, durum değiştirme ve claim operasyonları Admin/TV/Driver rollerine göre korunur.
- Public sipariş oluşturma açık kalır.
- Sipariş numarasıyla doğrudan takip GET isteği açık kalır; toplu sipariş listesi dışarıya kapanır.
- Driver yönetim PUT isteği yalnızca imzalı Admin oturumuyla yapılır.

3. Public settings temizliği
- TV PIN, dashboard password/token, Telegram bot token, admin/secrets bölümleri public cevaptan çıkarılır.
- Private settings görünümü artık yalnızca gerçek imzalı Admin cookie ile açılır.
- TV'nin productAvailability yazımı yalnızca gerçek imzalı TV/Admin oturumuyla yapılır.

4. Kurye şifre güvenliği
- Kurye şifreleri scrypt + benzersiz salt ile hashlenir.
- Eski düz şifre kayıtları ilk başarılı okumada otomatik ve kayıpsız biçimde hash'e çevrilir.
- Şifre/hash API GET cevabına veya localStorage'a gönderilmez.
- Kurye girişinden sonra imzalı HttpOnly driver session cookie oluşturulur.
- Çıkışta driver cookie temizlenir.

5. Stripe DB fiyat doğrulaması
- İstemcinin gönderdiği ürün, extra ve toplam fiyatlarına güvenilmez.
- Product fiyatı, aktiflik tarihleri ve extrasJson DB'den okunur.
- İçecek/extra varyantları sunucu settings kayıtlarından doğrulanır.
- Product/category kampanyası, standart Abholung/Lieferung indirimi, cart offer, ücretsiz ürün, kupon, route deal, Pfand, bahşiş ve split pay toplamı sunucuda yeniden hesaplanır.
- Bilinmeyen ürün/extra, pasif ürün veya değişmiş toplam Stripe açılmadan 409 ile reddedilir.
- Pending order ve final sipariş DB fiyatlarından oluşturulmuş canonical item/tutarlarla kaydedilir.

6. Secret/private key temizliği
- .gitignore; .env*, private key/cert, DB/dump, yerel print agent/proxy config ve build cache dosyalarını dışlar.
- GitHub betiği tracked gizli dosya ve olası gerçek private key/Stripe live key/Telegram token taraması yapar.

7. Bağımlılık güvenliği
- Next.js: 15.5.20
- Prisma / @prisma/client: 6.19.3
- @react-three/drei: 9.122.0
- Güvenli transitive overrides uygulanmıştır.
- npm audit sonucu: 0 total vulnerability.
