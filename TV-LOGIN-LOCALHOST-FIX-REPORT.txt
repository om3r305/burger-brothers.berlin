BURGER BROTHERS — TV LOGIN LOCALHOST FINAL FIX
===============================================

TESPİT EDİLEN GERÇEK NEDEN
--------------------------
Önceki TV login route'u 19051905 yerel fallback PIN'ini yalnızca
NODE_ENV != production olduğunda kabul ediyordu.

Bilgisayarda NODE_ENV=production kaldığında veya proje `next start` ile
production modunda localhost:3000 üzerinde çalıştırıldığında, gerçek adres
localhost olmasına rağmen 19051905 kabul edilmiyordu.

Ek olarak güvenli bb_tv_auth cookie'sinin üretilebilmesi için en az 32
karakterlik SESSION_SECRET gerekir. Yerel projede bu değer yoksa doğru PIN
sonrasında oturum oluşturma başarısız olur.

UYGULANAN DÜZELTME
------------------
1. Development runtime'da 19051905 yerel fallback kabul edilir.
2. Production runtime doğrudan localhost, *.localhost, 127.0.0.1 veya ::1
   üzerinde çalışıyorsa 19051905 kabul edilir.
3. Vercel production/preview ve gerçek burger-brothers.berlin domaininde
   19051905 fallback kesinlikle kabul edilmez.
4. Gerçek domainde DB-first TV PIN; DB'de yoksa TV_PIN env değeri kullanılır.
5. Kurulum, .env.local içinde güvenli SESSION_SECRET yoksa 48 byte rastgele
   secret üretir. Değer ekrana yazdırılmaz ve GitHub'a kopyalanmaz.
6. Session cookie HMAC imzası, HttpOnly ve production Secure davranışı korunur.

OTOMATİK TESTLER
----------------
- localhost + NODE_ENV=production => 19051905 kabul edilir.
- 127.0.0.1 + NODE_ENV=production => fallback kabul edilir.
- gerçek domain + NODE_ENV=production => fallback reddedilir.
- Vercel işareti + localhost spoof => fallback reddedilir.
- HMAC session ve API authorization testleri korunur.
- Driver password/session ve DB order-pricing testleri korunur.
